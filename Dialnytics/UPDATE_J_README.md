# Update J
1. Add call / Transfer-to-number: the number box was read-only. Now you can type, paste (Ctrl+V or the
   "Paste number from clipboard" button), and press Enter to call. Pasted text is cleaned (spaces, dashes, brackets removed).
2. Floating phone: button "Floating phone" at the top of the dialer panel opens a small always-on-top window
   (Chrome and Edge). It shows the number and timer and has Answer/Decline, Mute, Hold, Keypad and Hang up.
   Button is hidden in browsers that do not support it.
Files: base.html, dialer_rail.html, dialer.js, floating-phone.js. No database change.
