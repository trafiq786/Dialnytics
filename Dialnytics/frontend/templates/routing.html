Hybrid calling

Out = SIP, In = Twilio DID

Hybrid khud chalta hai jab EchoDial user ka number ek Twilio number ho: outbound call SIP provider se jati hai (CLI = wahi Twilio number), aur jab koi wapas call kare to Twilio par aati hai aur user ke dialer par ring hoti hai. Niche "inbound Twilio" us user ke liye ON dikhta hai.
